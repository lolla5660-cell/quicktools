Free Online Calculators, Text Tools and Converters

QuickTools provides simple browser-based tools for everyday calculations, text cleanup and unit conversions. The tools are designed to be fast, easy to understand and free to use.

Choose a calculator to work with percentages, discounts, age, tips, GPA or grades. Use the text tools to count words, change text case or remove duplicate lines. For measurements, use the converters for length, weight and temperature.

Why use QuickTools?
